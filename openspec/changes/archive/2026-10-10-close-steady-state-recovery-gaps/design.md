# Design

Preserve the October 3 continuity repairs and optional projectable metadata. Port the independently reproduced upstream fixes into the deployed beta.8 schema/runtime rather than importing unrelated newer migrations.

Terminal append tasks retain owned completion and attempt fences. Usage rejection classification is shared across HTTP and WebSocket paths. Same-owner proof does not authorize broad owner retirement; account-neutral projection retains its separate eligibility proof. Projection keeps reasoning ciphertext, compaction/search, native agent messages and complete tool histories where the backend accepts them. Visible-output, unknown-execution, resource-owner and settlement fences remain intact.

SQLite readiness records sustained busy evidence per resolved file path. At least two failures over 30 seconds enable one shared fresh-connection BEGIN IMMEDIATE/rollback/close probe, with 250 ms SQLite busy timeout, one-second caller observation and 30-second probe interval. Probe ownership survives caller cancellation; successful writes/probes clear degradation. PostgreSQL, memory SQLite and healthy operation avoid probes.

Iterator closure cascades through public-response and reasoning wrappers to the underlying stream. The disputed transport-to-quota error relabel is excluded.

Verification uses the 31-case public process matrix, focused route/database/lease tests, disposable concurrent SQLite pressure, and independent official beta.8 to fork to official swaps. Latest upstream main has an incompatible schema retirement boundary and requires a separate version upgrade.

Deployment installs a fingerprinted wheel with unchanged dependencies and model/migration files. An independent systemd job performs ordinary restart with default quick checking, verifies installed identity and endpoint health, and owns rollback on failure.
